# Manufacturing-analysis
Worked on analyzing production and operational data using Excel, SQL, Power BI, and Tableau to identify process inefficiencies, monitor KPIs, create interactive dashboards, and support data-driven decisions for improving productivity and reducing downtime.
Project Overview
The Manufacturing Analytics Project focuses on analyzing manufacturing and production data to identify operational inefficiencies, monitor production performance, and improve decision-making using data analytics tools. The project combines Excel, SQL, Power BI, and Tableau to generate meaningful business insights through interactive dashboards and backend data analysis.

 Objectives
Analyze manufacturing production data
Monitor key performance indicators (KPIs)
Identify rejection trends and operational inefficiencies
Create interactive dashboards for better visualization
Support data-driven business decisions

Tools & Technologies Used
Microsoft Excel – Data cleaning, preprocessing, KPI analysis
SQL – Database creation, querying, and backend analysis
Power BI – Interactive dashboard and visualization
Tableau – Advanced visual analytics and reporting

 Key Performance Indicators (KPIs)
Total Production
Total Processed Units
Total Rejected Units
Rejection Percentage
Total Revenue/Value
Employee Performance Analysis
Buyer-wise Production Analysis

 Features
Data cleaning and preprocessing
SQL-based production analysis
Interactive Power BI dashboard
Tableau visualization reports
KPI tracking and monitoring
Rejection and quality analysis
Operational performance insights

SQL Analysis
The SQL module includes:
Database and table creation
Aggregate functions (SUM, COUNT, AVG)
Production and rejection analysis
Employee performance evaluation
Rejection percentage calculations

 Key Insights
Identified departments with high rejection rates
Analyzed production efficiency gaps
Evaluated top-performing employees
Improved understanding of buyer-wise revenue contribution
Highlighted operational inefficiencies through processed vs produced quantity comparison

 Conclusion
This project demonstrates how manufacturing data can be transformed into actionable insights using analytics and visualization tools. Combining Excel, SQL, Power BI, and Tableau provides a complete end-to-end analytics solution for improving productivity, quality control, and business performance.
